# Simple Chat Web App

Build a simple chat web app using HTML, CSS, and JavaScript.

## Goal

Create a lightweight chat experience that demonstrates core JavaScript concepts such as functions and classes while staying easy to understand and use.

## Requirements

- Add a sign-up page connected to Supabase.
- Support anonymous users by asking only for a name before they continue.
- Let users wait for others to join and exchange messages in a random chat flow.
- Add an option to join servers.
- Keep the design and interactions simple.

## Suggested Pages

- Sign up / join page
- Random chat room
- Server selection page

## Behavior

- If a user is anonymous, prompt them for a name and continue.
- Allow users to join a random chat session.
- Show a waiting state when no other users are available.
- Let users send and receive messages in real time.
- Allow users to switch between random chat and servers.

## Implementation Notes

- Use plain HTML, CSS, and JavaScript.
- Use functions for reusable logic.
- Use classes where they make the code easier to organize.
- Keep the UI minimal and clean.

## Setup

- Open `index.html` in a browser to run the app.
- Add your Supabase project URL and anon key in `app.js` to enable sign up and sign in.
- Random chat and server rooms work across multiple tabs on the same device as a simple demo.
